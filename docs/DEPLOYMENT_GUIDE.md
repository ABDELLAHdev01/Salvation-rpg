# Salvation — Production Deployment & Local Verification Guide

**Document Version:** 1.0.0  
**Application Type:** Single-Page Progressive Web Application (React 19 + Phaser 3 + Vite)  
**Target Environment:** Static Web Hosting (Vercel, Cloudflare Pages, Netlify, or standard Nginx/Apache static web root)

---

## 1. Prerequisites
- **Node.js**: v18.0.0 or higher (v24.x tested and verified)
- **npm**: v9.0.0 or higher
- **Browser**: Modern Chromium, Edge, Firefox, or Safari with WebGL / HTML5 Canvas support

---

## 2. Production Build Execution

To generate the deployment-ready static distribution package:

```bash
# Navigate to the project root
cd projects/Salvation-rpg

# Install production and build dependencies
npm ci

# Run the optimized production build
npm run build
```

### Build Output Structure
The build generates all assets in the `dist/` directory:
- `dist/index.html`: Entry HTML with preloaded script headers and viewport configuration.
- `dist/assets/`:
  - `vendor-*.js`: Minified Phaser game engine and core libraries.
  - `WorldPage-*.js`: Dynamic React game UI components and modals.
  - `react-dom-*.js`: React 19 runtime.
  - `*.css`: Tailored Tailwind utility stylesheets.
  - `*.gz` & `*.br`: Pre-compressed Gzip and Brotli files generated by `vite-plugin-compression`.
- `dist/assets/tilesets/`, `dist/assets/trees/`, etc.: Public pixel-art asset packs and spritesheets.

## 3. Local Production Preview & Verification

To test the production build locally before uploading to a host:

```bash
# Preview the production dist folder
npm run preview
```

By default, Vite serves `dist/` at `http://127.0.0.1:4173/`.

### Automated End-to-End Verification Against Preview:
Run Playwright tests against the built application:

```bash
npm run test:e2e
```

All 6 test scenarios verify:
1. Canvas initialization and WebGL/Canvas context acquisition.
2. Movement and collision physics body updates.
3. Interactive triggers and zone transitions.
4. Tutorial progression lifecycle from Island to Mainland.

## 4. Deployment Platforms

### Option A: Cloudflare Pages
1. Connect Git repository.
2. Build command: `npm run build`
3. Build output directory: `dist`
4. Root directory: `projects/Salvation-rpg`

### Option B: Vercel
1. Framework preset: **Vite**
2. Build command: `npm run build`
3. Output directory: `dist`

### Option C: Nginx Static Host
Example Nginx configuration with SPA fallback and Brotli/Gzip delivery:

```nginx
server {
    listen 80;
    server_name salvation-rpg.local;
    root /var/www/salvation/dist;
    index index.html;

    # Serve pre-compressed Brotli and Gzip assets
    gzip_static on;
    brotli_static on;

    # Static asset caching
    location /assets/ {
        expires 1y;
        add_header Cache-Control "public, max-age=31536000, immutable";
    }

    # SPA history fallback
    location / {
        try_files $uri $uri/ /index.html;
    }
}
```
